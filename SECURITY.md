# Security Policy

If you discover a security vulnerability in ResumePress, please report it privately rather than opening a public issue.

- Preferred: open a [GitHub Security Advisory](../../security/advisories/new) for this repository.
- Alternatively, contact the maintainer directly.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any relevant logs or proof-of-concept code

We'll acknowledge reports as soon as possible and work with you on a fix and disclosure timeline.
